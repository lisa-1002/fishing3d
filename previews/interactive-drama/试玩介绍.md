# 问剑云深

竖屏 3D 试玩。石阶、山门、裂隙和三个人物是程序化几何，可以点地或触屏沿阶上行。`assets/kv-9x16.jpg` 是开始封面，`assets/bg-night.jpg` 只作远处天幕和结局底，不代替山门。

剧本以 `story.json` 为准，由 `app.js` 读取，界面样式在 `styles.css`。原先的 `index.html` 把对白写在页内，并没有引用这三份文件；`app.js` 期待的节点和页面也对不上。现在开始页、对白、分支、标签和两类结局都走这份 JSON。

玩法：踏入云梯后先听开场，再走到阿桃身边，或从她右侧绕上。扶她会多出「把剑推回」的第三问；绕过她则只有山门与深渊两柄影剑。结局是「剑心未钝」或「锋吞其人」。再问一剑回到开始页，人、信任和分支都会清掉。

备名「问心剑」「云阶问剑」不作标题。
