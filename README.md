# 静湖垂钓 3D（v2）

一款基于 **Three.js** 的 3D 写实风格钓鱼网页游戏（在线试玩：[GitHub Pages](https://lisa-1002.github.io/fishing3d/) · [itch.io](https://lisa-1002.itch.io/quiet-lake-fishing-3d)），手机（触屏）和电脑（鼠标/键盘）都能玩。纯静态站点，无需构建，Three.js 已本地化放在 `vendor/`，国内离线环境也能运行。

作者：**刘子峻**。原创代码与程序化美术见根目录 `LICENSE`；第三方素材见 `CREDITS.md`。

当前鱼模型由 `js/fish-gltf.js` 加载 `vendor/fish/real/` 的写实 CC0 GLB（见 `ART.md`）。鲤、黄金鲤、鲫、鲶、黄颡、黑鱼、马口、翘嘴、泥鳅、罗非、鳜鱼、黄鳝用 ffish.asia 的实鱼扫描；锦鲤王和其余大多鱼种仍是 Polyy / Khronos 低模。香鱼扫描在目录里但图鉴没有对应物种，不加载。`vendor/fish/Koi.glb`、`Goldfish.glb`、`ArmoredCatfish.glb` 是 Quaternius 历史文件，默认不加载。

## 〇、v2 更新内容

v1 玩家反馈“玩法单调”，v2 在保留写实画面和核心循环的基础上，新增了完整的养成与双钓法玩法：

### 1. 两种钓法（玩法完全不同）
**台钓竿（手竿，无渔轮）**
- 等漂时浮漂会有小幅点动 = **试口**，此时提竿会把鱼吓跑；鱼真正吃饵时浮漂会整个被拖入水中（**黑漂**）。
- 黑漂刚出现的一瞬间（约 0.3 秒 × 鱼竿灵敏度）提竿 = **完美提竿**：渔获估价 +10%、经验 +30%、搏鱼进度直接从 15% 开始。提示文字会在完美窗口结束后才出现，所以想拿完美必须自己“看漂”。
- 鱼饵影响咬口速度和鱼种（见下）。

**露亚竿（带纺车轮）**
- 抛出路亚饵后主动收线：**按住 = 收线加速，松开 = 停顿，轻点 = 抽竿**（饵向前窜一下）。
- 每种路亚饵有自己的**最佳收线速度区间**（速度条上的绿色区）。速度保持在区间内，**诱鱼值**上涨；抽竿有额外加成，但 2 秒内抽 6 下以上会把鱼吓跑。
- 诱鱼值够高时会有鱼影追在饵后面（“有鱼在追饵！”）。诱鱼值越高越容易攻击；鱼一咬饵（炸水），要在很短时间内点击**刺鱼**，刺得快 = 完美刺鱼。
- 饵收到脚下还没鱼攻击就算空军，重新抛投。
- 露亚的搏鱼更激烈：**甩头**（张力高频尖峰，要松手）、**冲刺**（进度倒退，要卸力）、掠食鱼还会**跃出水面**（3D 鱼模型跃出，此时线不能松，否则甩钩）。
- 露亚鱼池以掠食鱼为主，稀有以上概率更高：马口鱼、鲈鱼、鳜鱼、虹鳟、翘嘴、金龙鱼、黑鱼、鳡鱼。

右下角“台钓 / 露亚”按钮可快速切换（露亚竿需先获得）。

### 2. 鱼护与出售
- 钓到的鱼可以 **放入鱼护 / 直接出售 / 放生（+3 经验）**。
- 鱼护有容量（小 8 / 中 16 / 大 30），满了只能出售或放生。
- 鱼护面板可**单条出售**、**全部出售**，也可以给想留的鱼打“★保留”，全部出售时会跳过它们。
- 售价 = 鱼种基础价 ×（体重 / 平均体重）^0.85 × 完美加成。金币主要靠出售获得，每次上鱼只给一笔小额渔获奖励（约估价的 10%）。

### 3. 商店（金币购买，部分需要等级）
| 类别 | 内容 |
|---|---|
| 台钓竿 | 竹制（初始）→ 碳素 150 → 高碳竞技 600（Lv3）→ 金龙 2200（Lv6） |
| 露亚竿 | 入门 120 → 碳素路亚 520（Lv3）→ 大师枪柄 1800（Lv5） |
| 鱼竿属性 | **拉力**（降低鱼的拉扯、加快收线）、**灵敏**（延长提竿/刺鱼窗口、诱鱼更快）、**投远**；换竿后 3D 鱼竿颜色、长度、竹节/渔轮都会变 |
| 鱼线 | 尼龙（初始）→ 碳素线 120（断线张力 +12%）→ PE 450（+25%）→ 钛合金 1500（+40%） |
| 鱼饵（台钓消耗品） | 蚯蚓、玉米粒（鲤/草/黄金鲤）、活虾（鳜/鲈）、秘制窝料（史诗/传说概率↑）、锦鲤灵饵（锦鲤王） |
| 路亚饵（永久） | 亮片（中速）、米诺（快收 + 抽竿，翘嘴）、软虫（慢收，鳜鱼）、波爬（水面系，黑鱼）、雷蛙（巨物） |
| 鱼护 | 中号 200（Lv2）、大号 700（Lv4） |

**平衡**：新玩家初始有 50 金币和 10 条蚯蚓。普通鱼约卖 8~20 金币，钓 3 条鱼完成主线即可领取入门露亚竿和亮片；大约 5 分钟能买第一件升级（碳素线 / 碳素台钓竿 / 玉米）。

### 4. 任务
- **每日任务**：每天 0 点按日期刷新 3 个（同一天内固定），类型包括钓 N 条鱼、钓指定鱼种、钓到超过 X kg 的鱼、出售 N 金币、用露亚竿钓 N 条、完美提竿 N 次、钓稀有以上 N 条。难度越高奖励越好（金币 + 鱼饵 / 秘制窝料）。
- **主线 / 成就**：共 9 个，从“初次垂钓”（奖励露亚竿）到“图鉴大师”（奖励金龙台钓竿），奖励包括装备、鱼线、鱼护、稀有鱼饵。如果奖励的装备已经拥有，自动折算成金币。
- 有可领取的奖励时，任务按钮上会出现红点。

### 5. 等级与鱼种
- 每次上鱼获得经验（越稀有越多，完美有加成），最高 10 级。等级用来解锁更高级的装备。
- 鱼种从 10 种增加到 **15 种**，新增草鱼、马口鱼、翘嘴、黑鱼、鳡鱼。图鉴里会标注每种鱼适合的钓法。

### 5.1 鱼模型写实度（近期升级）
画面上的鱼优先用 `vendor/fish/real/` 里的写实 CC0 GLB（`js/fish-gltf.js`，见 `ART.md` 与 `CREDITS.md`）。鲤、黄金鲤、鲫、鲶、黄颡、黑鱼、马口、翘嘴、泥鳅、罗非、鳜鱼、黄鳝是 ffish.asia 实鱼扫描；其余有模型的鱼种仍是 Polyy / Khronos 低模。下面的程序化网格仍保留，只在对应 GLB 加载失败，或该物种没有写实外形（甲鱼）时使用：
- **体型按种**：鲤/锦鲤圆润深体、鲫/鳜侧扁、草鱼/翘嘴/龙鱼细长、黑鱼近圆柱、鲟/鳇细长带歪尾。
- **鳞片贴图**：Canvas 程序化生成圆鳞/大鳞/骨板 bump，与顶点色相乘；湿润清漆（clearcoat）+ sheen 模拟湿身高光。
- **花纹软边**：锦鲤红斑、鳜鱼豹斑、虹鳟侧带与黑点、黑鱼云斑等用噪声软过渡，避免色块硬切。
- **半透明鳍**：带鳍脉贴图与羽化透明，游动时高频轻颤。
- **眼睛**：巩膜 + 虹膜 + 瞳孔 + 高光点。
- **游动**：沿脊柱的 S 形弯曲（非单纯甩尾）；露亚搏鱼跃水时弓背、仰俯与滚转更接近真实跃水。


### 5.2 英雄级鲤鱼（对标三角洲行动收藏鱼）
**鲤鱼**、**黄金鲤**、**红白锦鲤王**默认走上一节的写实 GLB。GLB 不可用时，才使用独立的高模程序化管线 `js/fish-hero-carp.js`（其他鱼种在 GLB 失败时走通用程序化模型）：
- **几何**：更高密度体网格，深体侧扁、厚尾柄、吻部、**两对口须**、可动鳃盖；分片鳍（尾/背/臀/胸/腹）带鳍条感贴图。
- **PBR 贴图**（Canvas 程序化，高画质 1024² / 低画质 512²）：Albedo 圆鳞叠色、Roughness（背湿腹干）、Bump 鳞片浮雕、AO 缝隙；锦鲤红斑软边、黄金鲤高金属。
- **材质**：`MeshPhysicalMaterial` 高 clearcoat、sheen 暖腹、鳞片 **iridescence** 微彩虹。
- **动画**：脊柱 S 弯 + 鳍分区颤动（尾鳍大力、胸鳍划水）+ 鳃盖开合；跃水弓背。
- 渔获卡对英雄鱼使用近距灯光与 3/4 展示角，突出湿润高光。

目标气质参考《三角洲行动》中的红鲤王 / 彩鲤收藏物：游戏级鳞片密度与湿润高光，而非写实 CG 扫描。

## 一、技术选型理由：为什么先做 Three.js 网页版，而不是 Unity APP

| 维度 | Three.js 网页版（当前方案） | Unity APP |
|---|---|---|
| 安装门槛 | **免安装**，打开链接即玩 | 需下载安装包 / 上架应用商店 |
| 跨平台 | 一套代码同时覆盖 **手机 + 电脑**（iOS / Android / Windows / macOS 浏览器） | 需分别打包各平台 |
| 迭代速度 | 改完刷新即生效，无需编译打包、无需审核 | 编译、打包、商店审核周期长 |
| 分享传播 | **一个链接**就能发给朋友、发群、发朋友圈 | 需引导下载 |
| 后续扩展 | 可封装为 **微信小游戏**、H5 活动页，或用 Capacitor / WebView 打包成 APP | 原生性能更强 |
| 适合阶段 | 原型验证、玩法打磨、快速试错 | 重度 3D、复杂物理、上架商业发行 |

**结论**：现阶段的目标是快速验证“抛竿—等待—上钩—收线—收集”这一核心玩法是否好玩，Web 方案成本最低、反馈最快。等玩法验证成功、需要更重度的 3D 画面（大世界、高级水体、海量模型）或正式上架应用商店时，再迁移到 **Unity**（或 Cocos）会更合适；届时鱼种数据、数值、玩法逻辑都可以直接复用。

## 二、写实画面实现

为了尽量接近真实效果，场景、植被、码头和部分鱼种使用程序化生成。渔获默认另外加载 `vendor/fish/real/` 的写实模型（许可见 `CREDITS.md`）。

- **水面**：Three.js 官方 `Water`（实时平面反射 + 法线贴图 `textures/waternormals.jpg` 扰动 + 太阳高光），倒影中能看到山、树、码头、浮漂。该法线为本项目原创程序化贴图（CC0），见 `CREDITS.md`。
- **天空**：官方 `Sky`（大气散射模型），低角度午后阳光；并用 **PMREM** 从天空生成环境光照贴图，所有 PBR 材质（鱼、鱼竿、浮漂）都会反射真实天空。
- **色调**：ACESFilmic 色调映射 + sRGB 输出；**PCF 软阴影**；距离雾 / 大气透视让远山自然变淡。
- **地形**：分形噪声生成的湖岸、丘陵和远山，按高度和坡度着色（湿泥、沙滩、草地、林地、岩石）。
- **植被**：InstancedMesh 批量绘制上千棵针叶树和秋色阔叶树，岸边有芦苇丛。
- **码头**：程序生成木纹贴图（年轮、木结、风化颗粒）+ 凹凸贴图，每块木板颜色和角度略有差异；木桩、横梁、木桶、钓箱。
- **鱼模型**：默认使用 `vendor/fish/real/` 写实 GLB（头朝 +X、体长归一）。甲鱼以及 GLB 加载失败时，仍用按种定制的程序化体型、鳞片与游动（详见「5.1 鱼模型写实度」）。
- **鱼竿**：分段碳素鱼竿，随张力实时弯曲；软木手柄、纺车轮、导环。
- **特效**：落水水花粒子、扩散涟漪、远处随机鱼跃。

### 画质切换（高 / 低）
右上角「画质」按钮可切换（会刷新页面，设置保存在本地）：
- **高**：像素比最高 2、2048 阴影贴图、1024 反射分辨率、地形 256×256 网格、约 1400 棵树。
- **低**（手机默认）：像素比 ≤1.25、1024 阴影、256 反射、地形 128×128、约 450 棵树、关闭抗锯齿。

## 三、如何运行

需要通过 HTTP 访问（ES Module 不能用 `file://` 直接打开）：

```bash
cd fishing3d
python3 -m http.server 8080
# 电脑浏览器打开 http://localhost:8080
# 手机与电脑在同一 Wi-Fi 下，打开 http://<电脑局域网IP>:8080
```

也可以把整个目录上传到任意静态托管（GitHub Pages、Vercel、Netlify、腾讯云 COS、阿里云 OSS 等）直接访问。

| 渔获处理 | 卡片上选“放入鱼护 / 直接出售 / 放生” | 也可按空格（默认放入鱼护，满了就出售） |

## 六、下一步计划

- **音效与音乐**：水声、鸟鸣、抛竿呼啸、收线棘轮声、咬口提示音（Web Audio）。
- **多钓点**：用等级解锁河流、水库、海边，每个钓点有不同的鱼池和天气（等级系统已预留）。
- **昼夜与天气**：清晨、黄昏、夜钓、雨天，影响鱼种和咬口。
- **鱼饵/打窝深度玩法**：台钓调漂（调目/钓目）、窝料持续时间；露亚泳层（水面/中层/底层）。
- **社交**：排行榜、渔获分享卡片（需要后端）。
- **写实度继续提升**：扫描贴图或 glTF 鱼模型、水下视角、焦散、后期（Bloom、景深）。
- **平台化**：封装为微信小游戏，或用 Capacitor 打包 APP；如果要做重度 3D，再迁移到 Unity。
