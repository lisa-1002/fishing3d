# 静湖垂钓 3D（原型 v0.1）

一款基于 **Three.js** 的 3D 写实风格钓鱼网页游戏，手机（触屏）和电脑（鼠标/键盘）都能玩。纯静态站点，无需构建，Three.js 已本地化放在 `vendor/`，国内离线环境也能运行。

## 一、技术选型理由：为什么先做 Three.js 网页版，而不是 Unity APP

| 维度 | Three.js 网页版（当前方案） | Unity APP |
|---|---|---|
| 安装门槛 | **免安装**，打开链接即玩 | 需下载安装包 / 上架应用商店 |
| 跨平台 | 一套代码同时覆盖 **手机 + 电脑**（iOS / Android / Windows / macOS 浏览器） | 需分别打包各平台 |
| 迭代速度 | 改完刷新即生效，无需编译打包、无需审核 | 编译、打包、商店审核周期长 |
| 分享传播 | **一个链接**就能发给朋友、发群、发朋友圈 | 需引导下载 |
| 后续扩展 | 可封装为 **微信小游戏**、H5 活动页，或用 Capacitor / WebView 打包成 APP | 原生性能更强 |
| 适合阶段 | 原型验证、玩法打磨、快速试错 | 重度 3D、复杂物理、上架商业发行 |

**结论**：现阶段的目标是快速验证“抛竿—等待—上钩—收线—收集”这一核心玩法是否好玩，Web 方案成本最低、反馈最快。等玩法验证成功、需要更重度的 3D 画面（大世界、高级水体、海量模型）或正式上架应用商店时，再迁移到 **Unity**（或 Cocos）会更合适；届时鱼种数据、数值、玩法逻辑都可以直接复用。

## 二、写实画面实现

为了尽量接近真实效果，全部使用程序化生成，不依赖外部模型下载：

- **水面**：Three.js 官方 `Water`（实时平面反射 + 法线贴图 `textures/waternormals.jpg` 扰动 + 太阳高光），倒影中能看到山、树、码头、浮漂。
- **天空**：官方 `Sky`（大气散射模型），低角度午后阳光；并用 **PMREM** 从天空生成环境光照贴图，所有 PBR 材质（鱼、鱼竿、浮漂）都会反射真实天空。
- **色调**：ACESFilmic 色调映射 + sRGB 输出；**PCF 软阴影**；距离雾 / 大气透视让远山自然变淡。
- **地形**：分形噪声生成的湖岸、丘陵和远山，按高度和坡度着色（湿泥、沙滩、草地、林地、岩石）。
- **植被**：InstancedMesh 批量绘制上千棵针叶树和秋色阔叶树，岸边有芦苇丛。
- **码头**：程序生成木纹贴图（年轮、木结、风化颗粒）+ 凹凸贴图，每块木板颜色和角度略有差异；木桩、横梁、木桶、钓箱。
- **鱼模型**：参数化生成的侧扁鱼体（平滑着色），带尾鳍、背鳍、臀鳍、胸鳍、腹鳍和眼睛；顶点色实现背深腹浅渐变，以及每种鱼的花纹（竖纹、斑点、豹斑、彩虹带、锦鲤红斑、鲟鱼骨板等）；`MeshPhysicalMaterial` 清漆层模拟湿润高光；顶点着色器实现摆尾游动动画。
- **鱼竿**：分段碳素鱼竿，随张力实时弯曲；软木手柄、纺车轮、导环。
- **特效**：落水水花粒子、扩散涟漪、远处随机鱼跃。

### 画质切换（高 / 低）
右上角「画质」按钮可切换（会刷新页面，设置保存在本地）：
- **高**：像素比最高 2、2048 阴影贴图、1024 反射分辨率、地形 256×256 网格、约 1400 棵树。
- **低**（手机默认）：像素比 ≤1.25、1024 阴影、256 反射、地形 128×128、约 450 棵树、关闭抗锯齿。

## 三、如何运行

需要通过 HTTP 访问（ES Module 不能用 `file://` 直接打开）：

```bash
cd fishing3d
python3 -m http.server 8080
# 电脑浏览器打开 http://localhost:8080
# 手机与电脑在同一 Wi-Fi 下，打开 http://<电脑局域网IP>:8080
```

也可以把整个目录上传到任意静态托管（GitHub Pages、Vercel、Netlify、腾讯云 COS、阿里云 OSS 等）直接访问。

## 四、操作说明

| 操作 | 手机 | 电脑 |
|---|---|---|
| 蓄力抛竿 | 按住屏幕（或右下角按钮），松开抛出 | 按住鼠标左键 / 空格，松开抛出 |
| 瞄准方向 | 蓄力时左右拖动 | 蓄力时左右拖动鼠标，或 A / D、← / → |
| 收竿（鱼上钩） | 看到「鱼上钩了！点击收竿」时点击 | 点击鼠标 / 空格 |
| 收线 | 按住收线，松开放线 | 按住鼠标 / 空格收线 |
| 图鉴 | 右上角「图鉴」 | 同左 |

### 玩法规则
1. **抛竿**：力度条来回摆动，越远越容易钓到稀有鱼。
2. **等待**：浮漂偶尔轻点（试探），过早收竿会把鱼吓跑。
3. **上钩**：浮漂猛沉 + 提示 + 手机震动，需在约 1 秒内收竿，否则鱼跑掉。
4. **收线**：张力条要保持在绿色区域。鱼会周期性猛烈挣扎，张力过高（红色）持续一会儿就会**断线**；线太松太久鱼会**脱钩**；按住收线推动进度条，进度满即钓上。
5. **结算**：显示 3D 鱼模型和结果卡片（稀有度、名称、重量、金币），新鱼种自动收入图鉴，记录捕获次数和最重纪录（localStorage 本地保存）。

### 鱼种（10 种）
| 稀有度 | 颜色 | 鱼种 |
|---|---|---|
| 普通 | 灰白 | 鲫鱼、罗非鱼、鲤鱼 |
| 稀有 | 蓝 | 鲈鱼、鳜鱼、虹鳟 |
| 史诗 | 紫 | 黄金鲤、金龙鱼 |
| 传说 | 金 | 红白锦鲤王、千年鳇鱼 |

每种鱼的重量区间、难度（挣扎力度、收线速度、上钩反应窗口）和基础分都不同。

## 五、项目结构

```
fishing3d/
├── index.html          # 页面结构、HUD、import map（three -> 本地 vendor）
├── style.css           # 响应式 UI 样式（适配刘海屏安全区）
├── js/
│   ├── main.js         # 渲染器、鱼竿/浮漂/鱼线、输入、钓鱼状态机、HUD、存档
│   ├── world.js        # 天空、太阳、PMREM、Water 水面、地形、树木、芦苇、码头、小船、云
│   ├── fish.js         # 鱼种与稀有度数据、程序化鱼模型、图鉴缩略图
│   └── util.js         # 噪声与数学工具
├── vendor/
│   ├── three.module.js # Three.js r169（本地化，免 CDN）
│   └── addons/         # Water.js、Sky.js、RoomEnvironment.js、BufferGeometryUtils.js
├── textures/
│   └── waternormals.jpg# 水面法线贴图（来自 three.js 官方示例）
├── tools/verify.py     # 无头浏览器自动验证 + 截图脚本（Playwright）
└── screenshot*.png     # 运行截图
```

## 六、下一步计划

- **音效与音乐**：水声、鸟鸣、抛竿呼啸、收线棘轮声、上钩提示音（Web Audio）。
- **水下鱼影**：收线后期在浮漂附近显示游动的鱼影、跃出水面动画。
- **多钓点 / 昼夜天气**：湖泊、河流、海边；清晨、黄昏、夜晚、雨天，不同时段出不同的鱼。
- **装备成长**：用金币购买鱼竿、鱼线（提高断线阈值）、鱼饵（提高稀有鱼概率）。
- **任务与成就**、每日挑战、排行榜（需要后端）。
- **写实度继续提升**：真实扫描鱼贴图 / glTF 模型、水面焦散、体积雾、后期（Bloom、景深）、更真实的植被（billboard / 实例化草地）。
- **平台化**：封装为微信小游戏（Three.js 有小游戏适配方案）或用 Capacitor 打包 APP；若转重度 3D 再迁移 Unity。
